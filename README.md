# Bharat OS for Windows

Download the Bharat-OS-Windows artifact from the Build Bharat OS Windows EXE action, extract it and run Bharat-OS.exe. Python is bundled; no separate Python installation is needed. This is a desktop application, not a bootable operating system.

On first launch create a password of at least eight characters. Packaged app settings and password hashes are saved in %LOCALAPPDATA%\BharatOS. Wallpaper and Pillow are bundled.
